# SupportFlow Full-Stack Service

An enterprise-style IT incident triage and support workflow platform built with React, TypeScript, Python FastAPI, PostgreSQL (Supabase), and n8n.

## Repository Structure
- `/frontend` — React 18 + TypeScript + Vite + Tailwind CSS workspace & self-service portal
- `/backend` — Python FastAPI triage microservice & SLA rules engine
- `/automation` — n8n event-driven workflows & background escalation workers
- `/docs` — Architecture diagrams, user stories, and database schemas
